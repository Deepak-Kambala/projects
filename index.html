uarray · SciPy ecosystem

Getting a deprecation warning to point where it belongs

I came across this while looking into a SciPy FFT backend test failure. The trail led to uarray, the library behind the backend dispatch involved. With DeprecationWarnings treated as errors, a warning associated with skip_backend() was being reported from set_backend(), causing 46 test failures.

I fixed the warning attribution, adjusted its stacklevel, and added regression tests. The pull request was merged, and validation reported all 46 SciPy FFT backend tests passing with that warning configuration.
