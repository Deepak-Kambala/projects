Open source contributions

Quansight-Labs/uarray

A Python library for flexible dispatch and backend overrides, used across the scientific Python ecosystem.

Fix the warning location for skip_backend()

I came across this while looking into a SciPy FFT backend test failure. The trail led to uarray, the library behind the backend dispatch involved. With DeprecationWarnings treated as errors, a warning associated with skip_backend() was being reported from set_backend(), causing 46 test failures.

I fixed the warning attribution, adjusted its stacklevel, and added regression tests. The pull request was merged, and validation reported all 46 SciPy FFT backend tests passing with that warning configuration.

[Pull request][Original SciPy issue]

morluto/rea

An open source toolkit that helps AI agents reverse engineer software, from application behavior to native binaries.

fix(pe): accept WIN_CERTIFICATE padding counted in dwLength

Fixed certificate inspection for valid PE32 and PE32+ files whose WIN_CERTIFICATE.dwLength includes alignment padding. The parser now ends the CMS payload at its ASN.1 boundary and accepts only zero-filled bytes needed for alignment.

Made REA’s existing guided investigation workflows available to clients that cannot use native MCP prompts. The CLI command and provider-free MCP tool can list workflows and render their guidance using the same contracts, without starting an analysis or interacting with a target.

Added CLI and MCP search and retrieval for REA’s installed workflow guides. Analysts can search by question, see ranked matching sections, and retrieve a full section from a bundle-bound locator. Results are clearly identified as documentation, not analysis evidence.
